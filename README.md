# Electronics India

A responsive business website with a homepage and dedicated services page for Electronics India, an LED TV repair and electronics service based in Kishangarh, Vasant Kunj, New Delhi. Built with HTML5, CSS3 and vanilla JavaScript; no build step or runtime dependencies are required.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static file server. For example, from this directory run `python -m http.server 8000` and visit `http://localhost:8000`.

## Before publishing

- Replace `https://electronics-india.example/` in the canonical URL, JSON-LD `@id`, and JSON-LD `url` with the final public website URL.
- Replace the explicit email placeholder `owner.email@electronics-india.example` with the owner's real email address before going live. The `mailto:` link is intentionally configured as a clear placeholder because no email address was supplied.
- Keep the existing business photos in `images/` unchanged; service-card photos are stored separately there.
